# Скидки Тбилиси

Сборщик для сайта «Атлас стиля». Каждый день в 09:00 по Тбилиси (в Black Friday и январскую распродажу — 4 раза в день):

1. Проверяет вещи из плана покупок (`watch.json`): цена, старая цена, есть ли нужный размер.
2. Ищет уценки от 30% в мужских разделах Zara Грузия и отбирает по составу: 80%+ шерсть, кашемир, лён, хлопок или натуральная кожа; у обуви — не синтетическая подкладка.
3. Сохраняет `data/latest.json` (его читает сайт, раздел «Скидки») и историю цен `data/history/`.
4. Если есть новости — шлёт одно сообщение в Telegram.

## Что отслеживается

| Магазин | Как | Что |
|---|---|---|
| Zara Грузия | открытый JSON сайта | вещи из плана + уценки |
| Massimo Dutti Грузия | открытый каталог | только вещи из плана |
| Meermin, Oliver Cabell, Johnstons | Shopify JSON | вещи из плана, цена в ₾ с НДС 18% |
| BOSS, AllSaints, END, Arttime, City Mall, Outlet Village | — | не отслеживаются: нет открытых цен или защита от ботов |

Защита от ботов и капчи не обходятся.

## Настройка

- Размеры, курсы, порог скидки, фильтр по составу — `config.json`.
- Список вещей — `watch.json`.
- Telegram: секреты репозитория `TG_TOKEN` и `TG_CHAT_ID` (Settings → Secrets and variables → Actions).
- Запустить вручную: вкладка Actions → «Скидки» → Run workflow. Локально: `python scrape.py --dry` (ничего не пишет и не отправляет).
